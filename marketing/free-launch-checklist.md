# Free launch checklist

## Service
MailerLite Free currently lists 250 active subscribers, 2,500 monthly emails, three automations, and one hosted landing page. Confirm the account's current plan and terms before activation. Do not enter a credit card or accept a paid upgrade if your requirement is $0.

## Setup (account owner approval required)
1. Sign up at https://www.mailerlite.com/ and choose Free. Complete email/domain and business verification requests.
2. Build a hosted landing page from marketing/landing-page-copy.md. Configure a signup form, explicit consent language, and a privacy notice. Set up the hosted thank-you page.
3. Publish and link the free guide only once the actual guide file exists.
4. Create a subscriber group, then build a visual automation triggered when a new consenting subscriber joins it.
5. Add the five email messages in marketing/email-sequence.md. Use delays 2, 2, 3, and 7 days between sends.
6. Test with your own consenting address, verify the guide link, delivery, unsubscribe, and mobile layout.
7. Apply directly to affiliate programs; only use actual approved tracking URLs and make affiliate disclosures near links.
8. Review MailerLite's real subscriber and click analytics and affiliate-network confirmed payouts rather than guessed numbers.

## No-cost operating boundary
Don't buy a domain, advertising, a website subscription, AI credits, or an email upgrade without a separate decision. There is no guarantee of visitors, subscribers, or commissions. GitHub Actions currently generates drafts only; MailerLite handles opted-in delivery when configured.

## Security
Never paste API keys into a public repository or public conversation. Use service-specific credential controls and GitHub Actions repository secrets if integration is later needed.
